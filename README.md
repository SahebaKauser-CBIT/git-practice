# Git Practice

## About This Project

This repository is part of my internship training. It helps me learn Git, GitHub, version control, and basic web development.

## Project Files

* `index.html` - Landing page describing my internship goals.
* `about.html` - About page describing my background.
* `css/style.css` - Styles for the web pages.
* `.gitignore` - Prevents temporary and unwanted files from being tracked.

## Git Commands Learned

* `git init` - Initializes a Git repository.
* `git status` - Shows the current status.
* `git add` - Stages files.
* `git commit` - Saves changes.
* `git branch` - Manages branches.
* `git switch` - Switches branches.
* `git remote add` - Connects a remote repository.
* `git push` - Uploads commits to GitHub.
* `git log` - Displays commit history.

## Learning Goals

* Understand version control.
* Practise feature branches.
* Learn collaborative development.
* Publish a project on GitHub.
